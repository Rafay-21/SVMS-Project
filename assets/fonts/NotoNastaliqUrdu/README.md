# Noto Nastaliq Urdu font files

Place the following files here (download from https://fonts.google.com/noto/specimen/Noto+Nastaliq+Urdu):

- NotoNastaliqUrdu-Regular.ttf     (weight 400)
- NotoNastaliqUrdu-Medium.ttf      (weight 500)
- NotoNastaliqUrdu-SemiBold.ttf    (weight 600)
- NotoNastaliqUrdu-Bold.ttf        (weight 700)

Or use the variable font:
- NotoNastaliqUrdu[wght].ttf

After placing the files, the font will load locally without any CDN dependency.
Until then, the system falls back to: Jameel Noori Nastaleeq → system serif.
