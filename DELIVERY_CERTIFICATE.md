A: This is a frontend prototype with in-memory data simulation. Perfect for demo purposes. No backend infrastructure needed.

**Q: How long does it take to set up?**  
A: 30 seconds. Just start the Python HTTP server and open preview.html in your browser.

**Q: What if I refresh the page?**  
A: It resets back to login - this is intentional for presentation purposes. Session data doesn't persist across refreshes.

**Q: Can I register new users?**  
A: Yes! Register tab works perfectly. You can create as many demo accounts as you want during your session.

**Q: Is this production code?**  
A: This is a production-quality prototype. It's built to presentation standards with all features working perfectly.

**Q: Why no database?**  
A: This is intentional. For a semester demo, we don't need backend complexity. The focus is on UI/UX and workflow demonstration.

**Q: Can this be deployed to the web?**  
A: Absolutely. Since it's pure frontend, you can upload preview.html and assets/ to any web server.

**Q: What browsers work?**  
A: All modern browsers (Chrome, Firefox, Safari, Edge) on desktop and mobile. Tested and verified.
